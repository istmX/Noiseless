# Noiseless Orange Signal Landing World

## Thesis

Noiseless turns continuous research into a warm editorial signal world. It refuses the generic software hero and shows the agent as a living process that resolves a moving web into a useful brief.

## Visual world

The page uses an orange studio background, peach framed surfaces, cream paper sections, and dense ink typography. Organic circles, rings, soft shadows, and paper line texture create the visual language. The world is playful and tactile without becoming childish.

The public landing page does not inherit the authenticated workspace palette. Its local visual variables live in `LandingPage.module.css` so the public art direction can evolve independently.

## First viewport

The first viewport is a framed poster. Navigation sits at the top. Oversized copy sits on the left with the primary action. A large orange signal composition sits on the right with a center node, orbital rings, an active label, and a watch identity. The page reads as an authored object before it reads as a product layout.

## Eight section story

1. Framed signal poster
2. The attention premise
3. Agent pipeline
4. Watch product proof
5. Research fields
6. Evidence chain
7. First watch pricing action
8. Final signal invitation

## Typography

Use a geometric system sans with strong size contrast, tight display tracking, and short lines. Small labels use uppercase tracking. Body text stays calm and readable. Italics are used as a visual counterpoint in display headings.

## Components

The page uses framed poster surfaces, paper editorial sections, an asymmetric pipeline, a simulated watch panel, evidence rows, and a single pricing card. It must not collapse into a repeated grid of identical cards.

## Motion

GSAP owns the expressive moments. The hero uses a staged entrance, orbital rotation, floating signal orbs, a paper curl, and a scan line. Scroll reveals use bounded ScrollTrigger instances. A small parallax movement is reserved for the final organic blob. Reduced motion removes movement while keeping the page visible.

## Accessibility

Use semantic sections, keyboard reachable links, visible focus, readable contrast, mobile navigation controls, meaningful labels for the signal artwork, and reduced motion support.
